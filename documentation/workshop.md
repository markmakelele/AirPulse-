# AirPulse™ Stakeholder Workshop

## Purpose
Move from passenger behaviours and pain points to prioritized service opportunities and testable service requirements.

## 90-minute flow
00–10 Introduction
10–25 Journey walkthrough
25–40 Pain-point discussion
40–55 Opportunity generation
55–70 Prioritisation
70–82 Service response
82–90 Action planning

## Core outputs
- Priority journey moments
- Opportunity set
- Now / Next / Later prioritisation
- Service-response definitions
- Owners, next actions and evidence needed
