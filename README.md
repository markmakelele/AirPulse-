# AirPulse™

AirPulse™ is a context-aware airport navigation service explored as three connected artefacts:

1. **Repository** — the source of truth for research, service design, prototypes and documentation.
2. **Project** — a UX/service-design case study focused on reducing cognitive load during airport navigation.
3. **Package** — a reusable AirPulse Service Design Kit containing journey maps, service blueprints, Gantt views, workshop boards, opportunity mapping and validation materials.

## Core proposition

> AirPulse adapts to the passenger, so the passenger can focus on the journey.

## Current service model

Passenger journey:
**Arrival → Check-in → Security → Immigration → Wayfinding → Gate → Boarding**

Service layers:
**Customer Journey → Frontstage Actions → Backstage Actions → Support Processes**

Primary service modes:
- Smart guidance
- Ambient alerts
- Haptic feedback
- Audio directions
- Live updates
